## 1. Dane podstawowe (Product Details)

- **Nazwa aplikacji (Tytuł - maks. 30 znaków):**
  `Kompas cyfrowy • Dark Titanium`
  *(lub prościej: `Kompas`)*

- **Krótki opis (Short Description - maks. 80 znaków):**
  `Precyzyjny kompas 3D z ciemnym motywem OLED, bez reklam i bez śledzenia.`

- **Pełny opis (Full Description - maks. 4000 znaków):**
```
Kompas to minimalistyczny, precyzyjny i elegancki cyfrowy przyrząd nawigacyjny zaprojektowany z myślą o nowoczesnych smartfonach.

Główne cechy:
• Wysoka precyzja: Wykorzystuje sprzętowy sensor wektora rotacji (akcelerometr + magnetometr) dla natychmiastowej reakcji igły 3D.
• Motyw Dark Titanium: Zoptymalizowany pod ekrany OLED – piksele tła są wygaszone, co drastycznie redukuje zużycie baterii.
• Brak białego błysku: Natychmiastowy, płynny start w ciemnej tonacji bez względu na motyw systemu.
• 100% prywatności: Aplikacja nie zbiera, nie przechowuje ani nie wysyła żadnych danych użytkownika. Działa całkowicie w trybie offline.
• Zero reklam: Żadnych banerów, powiadomień ani mikropłatności.
• Zgodność z Edge-to-Edge: Pełne wykorzystanie nowoczesnych ekranów z bezpiecznym omijaniem wycięcia aparatu.

Niezbędny przyrząd w terenie, w podróży oraz podczas prac montażowych.
```
